# Libra 的博客站点

这个仓库主要用于存储并发布我的个人博客网页文件。

博客使用 Hexo 生成静态页面，并通过 GitHub Pages 对外访问。这里保存的是生成后的网页内容，适合作为站点发布目录；文章源文件通常维护在 Hexo 项目的 `source/_posts/` 目录中。

博客地址：https://moyu-yunru.github.io/

如果你也想搭建一个类似的网站，可以参考这篇文章：

[使用 Hexo 写博客，并发布到 GitHub Pages](https://moyu-yunru.github.io/2026/05/23/hexo-github-pages-guide/)
